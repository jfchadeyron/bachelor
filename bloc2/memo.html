Debian : système et diagnostic

Besoin Commande
nom, adresses, routes hostname -f, ip -br a (carte ens18), ip route
configuration réseau fixe /etc/network/interfaces (adresse, passerelle) ; /etc/resolv.conf (DNS)
agent invité QEMU sudo apt install qemu-guest-agent ; systemctl status qemu-guest-agent
DNS utilisés, résoudre un nom cat /etc/resolv.conf ; getent hosts nom
heure et synchronisation timedatectl, timedatectl timesync-status
état d’un service systemctl status nginx, systemctl is-active mariadb, systemctl --failed
démarrer, arrêter, au démarrage sudo systemctl start / stop / restart / enable --now service
journaux d’un service journalctl -u nginx -n 50, journalctl -u ssh --since "-1h"
erreurs récentes journalctl -p err --since today
ports en écoute sudo ss -tlnp (TCP), sudo ss -ulnp (UDP), sudo ss -xlp (sockets locaux)
espace disque df -h, sudo du -xh / --max-depth=2 | sort -h | tail
mémoire, processus free -h, top, ps aux --sort=-%cpu | head
tâches planifiées (minuteurs) systemctl list-timers --no-pager
lancer une commande en tâche de fond sudo systemd-run --unit=nom commande ; l’arrêter : sudo systemctl stop nom
tester une page web curl -s -o /dev/null -w "%{http_code} %{time_total}\n" http://IP/ ; curl -v http://IP/
configuration valide ? sudo nginx -t, sudo php-fpm8.4 -t, sudo apache2ctl configtest, sudo rsyslogd -N1, sudo nagios4 -v /etc/nagios4/nagios.cfg

Plugins de supervision (Monitoring Plugins)

Commande Rôle
/usr/lib/nagios/plugins/check_ping -H IP -w 100,20% -c 500,60% joignabilité (temps en ms, pertes)
check_tcp -H IP -p 80 un port TCP accepte la connexion
check_http -I IP -u /sante.php -s BASE-OK page web avec texte requis (check_curl : mêmes options, remplaçant de check_http sous Debian 13)
check_dns -H nom -s IP-DU-DNS -a IP-ATTENDUE réponse d’un DNS
check_disk -w 20% -c 10% -p / espace libre
check_load -r -w 0.8,0.7,0.6 -c 1.5,1.2,1.0 charge (par cœur avec -r)
check_procs -C nginx -c 1: au moins un processus
check_apt mises à jour en attente
echo $? code retour : 0 OK, 1 WARNING, 2 CRITICAL, 3 UNKNOWN

SNMP (Net-SNMP)

Commande Rôle
snmpget -v2c -c COMMUNAUTE IP .1.3.6.1.2.1.1.5.0 lire un OID (ici sysName)
snmpwalk -v2c -c COMMUNAUTE IP .1.3.6.1.2.1.1 parcourir une branche
snmpget -v3 -l authPriv -u UTIL -a SHA-256 -A MDP-AUTH -x AES -X MDP-CHIFF IP OID lire en SNMPv3 authentifié et chiffré
~/.snmp/snmp.conf paramètres v3 par défaut (defVersion 3, defSecurityName…)
snmptranslate -On NOM / -Td NOM traduire un nom en OID / décrire un objet
/etc/snmp/snmpd.conf, /var/lib/snmp/snmpd.conf configuration de l’agent ; utilisateurs v3 (createUser, service arrêté)

Zabbix 7.0

Besoin Commande ou fichier
services zabbix-server, zabbix-agent2 ; sudo tail /var/log/zabbix/zabbix_server.log
configuration du serveur /etc/zabbix/zabbix_server.conf (DBPassword=)
configuration de l’agent /etc/zabbix/zabbix_agent2.d/hexalog.conf (Server=, ServerActive=, Hostname=)
tester la configuration de l’agent sudo zabbix_agent2 -T -c /etc/zabbix/zabbix_agent2.conf
calculer une clé sur la machine zabbix_agent2 -t 'vfs.fs.size[/,pused]' -c /etc/zabbix/zabbix_agent2.conf
interroger un agent depuis le serveur zabbix_get -s IP -k agent.version
ajouter une clé maison UserParameter=nom.cle,commande dans un fichier de zabbix_agent2.d/
lire un journal élément Agent Zabbix (actif), type Journal : log[/var/log/auth.log,"motif",,,skip] ; eventlog[Security,,,,4625,,skip]
Expression de déclencheur Sens
last(/hôte/clé)>90 dernière valeur
min(/hôte/clé,5m)>2 / max(…,5m)<0.8 toujours au-dessus / toujours en dessous pendant 5 min
avg(/hôte/clé,10m)>1 moyenne sur 10 min
count(/hôte/clé,5m)>=5 nombre de valeurs (lignes de journal) sur 5 min
nodata(/hôte/clé,5m)=1 aucune valeur depuis 5 min
timeleft(/hôte/clé,1h,100)<1d seuil atteint dans moins d’un jour, au rythme de la dernière heure
now()-last(/hôte/vfs.file.time[fichier])>7200 fichier non modifié depuis plus de 2 h

Sauvegarde et restauration

Besoin Commande
exporter une base sudo mariadb-dump --single-transaction --routines --triggers intranet | gzip > fichier.sql.gz
vérifier une archive gzip -t fichier.sql.gz
restaurer dans une base à part sudo mariadb -e "CREATE DATABASE intranet_restau" puis sudo zcat fichier.sql.gz | sudo mariadb intranet_restau
lister les minuteurs de sauvegarde systemctl list-timers 'sauvegarde-*' 'copie-*' --no-pager
résultat d’une sauvegarde journalctl -u sauvegarde-intranet -n 20
copier en tirant, en lecture seule rsync -rt -e "ssh -i CLE" copie@IP: DEST/ ; côté source : command="/usr/bin/rrsync -ro DOSSIER",restrict dans authorized_keys
état de l’activité simulée sudo bash activite-intranet.sh etat
