VirtualBox (VBoxManage)

Commande Rôle
VBoxManage list vms / list runningvms lister les VM / celles qui tournent
VBoxManage showvminfo NOM configuration d’une VM
VBoxManage snapshot NOM take NOM-SNAP prendre un snapshot
VBoxManage snapshot NOM list / restore NOM-SNAP lister / restaurer
VBoxManage natnetwork list réseaux NAT
VBoxManage natnetwork add --netname LAB-HEXALOG --network "10.10.10.0/24" --enable --dhcp on créer un réseau NAT
VBoxManage natnetwork modify --netname LAB-HEXALOG --dhcp off désactiver son DHCP
VBoxManage natnetwork modify --netname LAB-HEXALOG --port-forward-4 "nom:tcp:[127.0.0.1]:8080:[10.10.10.20]:80" ajouter une redirection
VBoxManage natnetwork modify --netname LAB-HEXALOG --port-forward-4 delete nom supprimer une redirection
VBoxManage export NOM -o NOM.ova exporter une VM

Linux : comptes et droits

Commande Rôle
id NOM, getent passwd NOM, getent group GROUPE identité, groupes
sudo useradd -m -s /bin/bash -G g1,g2 NOM créer un utilisateur
sudo passwd NOM, echo "NOM:MDP" | sudo chpasswd définir un mot de passe
sudo groupadd GROUPE créer un groupe
sudo usermod -aG GROUPE NOM ajouter à un groupe (toujours -aG)
sudo gpasswd -d NOM GROUPE retirer d’un groupe
sudo usermod -L / -U NOM verrouiller / déverrouiller
sudo chage -l NOM, sudo chage -M 365 -E AAAA-MM-JJ NOM expiration
sudo userdel -r NOM supprimer avec le dossier personnel
ls -l, ls -ld DOSSIER droits
chmod 750 F, chmod u+x,g-w F, chmod 2770 DOSSIER modifier les droits
sudo chown user:groupe F, sudo chgrp -R groupe D propriétaire, groupe
umask, umask 027 masque de création
getfacl F, sudo setfacl -m g:GROUPE:rx D lire / ajouter une ACL
sudo setfacl -d -m g::rwx,o::--- D ACL par défaut (héritage)
sudo -u NOM commande tester en tant qu’un autre utilisateur
sudo visudo -f /etc/sudoers.d/FICHIER, sudo visudo -c règles sudo
sudo -l, sudo -l -U NOM droits sudo
sudo journalctl _COMM=sudo traces sudo

SSH

Commande Rôle
ssh-keygen -t ed25519 -C "commentaire" créer une paire de clés
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@hôte déposer la clé publique
ssh user@hôte, ssh -p 2222 user@127.0.0.1 se connecter
ssh -J bastion user@cible rebond par un bastion
ssh -N -L 13389:10.10.10.10:3389 bastion tunnel vers un port interne
eval "$(ssh-agent)", ssh-add agent SSH
ssh-keygen -lf fichier.pub empreinte d’une clé
ssh-keygen -R "[127.0.0.1]:2222" oublier une empreinte
scp F user@hôte:/chemin, scp -P 2222 …, sftp hôte transferts
sudo sshd -t, sudo sshd -T tester / afficher la configuration effective
sudo journalctl -u ssh connexions

Côté Windows (PowerShell), déposer une clé sans ssh-copy-id :

Machine : PC Windows
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | ssh -p 2222 user@127.0.0.1 "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

UFW

Commande Rôle
sudo ufw default deny incoming / allow outgoing politiques par défaut
sudo ufw allow 80/tcp ouvrir un port à tous
sudo ufw allow from 10.10.10.30 to any port 22 proto tcp ouvrir à une seule source
sudo ufw enable / disable activer / désactiver
sudo ufw status verbose, sudo ufw status numbered état, règles numérotées
sudo ufw delete N supprimer la règle N
sudo journalctl -k | grep 'UFW BLOCK' paquets refusés

Active Directory

New-ADUser -Name … -SamAccountName … -UserPrincipalName … -Path … -AccountPassword … -Enabled $true créer un utilisateur
Add-ADGroupMember G -Members u, Remove-ADGroupMember G -Members u appartenance

Set-ADAccountPassword u -Reset -NewPassword (Read-Host -AsSecureString) réinitialiser

Get-ADDefaultDomainPasswordPolicy, Get-ADUserResultantPasswordPolicy u politiques de mot de passe

Partages et NTFS

Commande Rôle
icacls D afficher les permissions
icacls D /grant "HEXALOG\GROUPE:(OI)(CI)M" Modification, héritée partout
icacls D /grant "HEXALOG\GROUPE:(OI)(CI)RX" Lecture et exécution
icacls D /inheritance:r supprimer l’héritage
icacls D /save fichier.txt /t sauvegarder les permissions
New-SmbShare -Name N -Path D -FullAccess … -ChangeAccess … -FolderEnumerationMode AccessBased créer un partage avec ABE
Get-SmbShare, Get-SmbShareAccess -Name N partages et permissions de partage
New-FsrmQuota -Path D -Size 500MB quota
smbclient //serveur/partage -U 'HEXALOG\u' -c 'ls' (Linux) tester un accès
