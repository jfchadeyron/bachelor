Cours de la séance 5

Windows Server : services, réseau, stockage

Les bases de l'administration d'un serveur Windows : les éditions et les modes d'installation, la configuration initiale, les rôles et fonctionnalités, les services, les journaux d'événements, le réseau et le pare-feu, les disques et les mises à jour. Avec une méthode de dépannage qui commence toujours par lire les journaux.

1. Windows Server en entreprise

Versions et éditions

Microsoft publie une version de Windows Server tous les 3 ans environ (2016, 2019, 2022, 2025), chacune supportée une dizaine d’années (5 ans de support standard + 5 ans de support étendu). Deux éditions principales :

Standard Datacenter
Fonctions quasi identiques + fonctions avancées de stockage et de réseau logiciel
Droits de virtualisation 2 VM Windows Server par licence VM Windows Server illimitées sur l’hôte
Usage serveurs physiques ou peu de VM hôtes de virtualisation très chargés

La licence se calcule par cœur de processeur. Chaque utilisateur ou appareil qui accède au serveur a aussi besoin d’une licence d’accès client (CAL). Pour le lab, on utilise la version d’évaluation gratuite de 180 jours.

Expérience de bureau ou Server Core

Expérience de bureau Server Core
Interface bureau Windows complet invite de commande et PowerShell uniquement
Surface d’attaque plus grande réduite (moins de composants à corriger)
Mises à jour et redémarrages plus fréquents moins fréquents
Ressources plus de disque et de RAM moins
Administration locale, graphique à distance (Gestionnaire de serveur, Windows Admin Center, PowerShell)

Microsoft recommande Server Core pour la production. Dans le lab, on prend l’Expérience de bureau pour apprendre avec les outils graphiques, en pratiquant PowerShell à côté.

2. La configuration initiale

Juste après l’installation, un serveur porte un nom aléatoire (WIN-7K3J...), reçoit son adresse par DHCP et n’est pas à jour. La liste de contrôle :

  1. Nom conforme à la convention (SRV-WIN-01) ;
  2. adresse IP fixe, masque, passerelle, DNS ;
  3. fuseau horaire et heure correcte (indispensable pour Active Directory) ;
  4. mises à jour ;
  5. accès à distance (bureau à distance, gestion à distance) ;
  6. pare-feu actif, règles vérifiées ;
  7. antivirus (Microsoft Defender est intégré) ;
  8. documentation : inventaire, mot de passe administrateur stocké dans un coffre.

Les outils :

  • Gestionnaire de serveur : tableau de bord, ajout de rôles, gestion de plusieurs serveurs ;
  • sconfig : menu texte de configuration (nom, réseau, mises à jour, bureau à distance), présent aussi en Server Core ;
  • PowerShell : tout se fait en ligne de commande, et donc s’automatise ;
  • les consoles .msc : services.msc, eventvwr.msc, diskmgmt.msc, wf.msc, compmgmt.msc ;
  • Windows Admin Center : console web d’administration (installation séparée).
Machine : SRV-WIN-01 (PowerShell administrateur)
Rename-Computer -NewName "SRV-WIN-01" -Restart
Get-NetAdapter                                     # nom de la carte (souvent "Ethernet")
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 10.10.10.10 -PrefixLength 24 -DefaultGateway 10.10.10.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses X.X.X.X   # DNS relevé à la séance 3
Get-NetIPConfiguration                             # vérification
Get-TimeZone                                       # fuseau horaire

3. Rôles, fonctionnalités et services

  • Un rôle est une fonction principale rendue aux utilisateurs ou au réseau : AD DS (annuaire), DNS, DHCP, Serveur de fichiers, IIS (serveur web), Hyper-V, services de déploiement…
  • Une fonctionnalité est un composant technique d’appoint : outils d’administration (RSAT), Sauvegarde Windows Server, BitLocker, clustering, .NET…
  • Un service est un programme qui tourne en arrière-plan, sans utilisateur connecté. Installer un rôle ajoute généralement un ou plusieurs services (le rôle IIS ajoute le service W3SVC).
Machine : SRV-WIN-01 (PowerShell administrateur)
Get-WindowsFeature | Where-Object Installed          # ce qui est installé
Install-WindowsFeature Web-Server -IncludeManagementTools
Uninstall-WindowsFeature Web-Server

4. Les services

Chaque service a :

  • un état : en cours d’exécution, arrêté, suspendu ;
  • un type de démarrage : Automatique, Automatique (début différé), Manuel (démarré à la demande), Désactivé (ne peut pas démarrer) ;
  • un compte d’exécution : LocalSystem (tous les droits sur la machine), NetworkService, LocalService (droits réduits) ou un compte de service dédié ;
  • des dépendances : un service ne démarre pas si un service dont il dépend est désactivé ;
  • des actions de récupération en cas d’arrêt inattendu (redémarrer le service, exécuter un programme…).
Machine : SRV-WIN-01 (PowerShell administrateur)
Get-Service W3SVC                                    # état
Get-Service W3SVC -RequiredServices                  # de quoi dépend-il ?
Get-CimInstance Win32_Service -Filter "Name='W3SVC'" | Select-Object Name, StartMode, State, StartName
Start-Service W3SVC ; Stop-Service W3SVC ; Restart-Service W3SVC
Set-Service W3SVC -StartupType Automatic
sc.exe qc W3SVC                                      # configuration complète, dépendances comprises

Analogie

Un service, c’est un employé de nuit : il travaille même quand personne n’est connecté. Son type de démarrage dit s’il arrive tout seul le matin (automatique), s’il vient quand on l’appelle (manuel) ou s’il est en congé (désactivé). S’il dépend d’un collègue en congé, il ne peut pas travailler.

5. Les journaux d’événements

Windows enregistre tout ce qui se passe dans des journaux, consultables avec l’Observateur d’événements (eventvwr.msc) :

Journal Contenu
Système événements du système et des services (démarrages, arrêts, erreurs de pilote)
Application événements des applications
Sécurité ouvertures de session, gestion des comptes, accès (audit, séance 13)
Journaux des applications et services journaux détaillés par composant (DNS, bureau à distance, PowerShell…)

Chaque événement a une date, une source, un niveau (Critique, Erreur, Avertissement, Information) et un ID. Quelques ID utiles de la source Service Control Manager : 7000 (le service n’a pas pu démarrer), 7001 (dépendance en échec), 7009 (délai dépassé), 7023/7024 (arrêt sur erreur), 7031/7034 (arrêt inattendu), 7036 (changement d’état), 7040 (type de démarrage modifié).

Machine : SRV-WIN-01 (PowerShell administrateur)
Get-WinEvent -LogName System -MaxEvents 20
Get-WinEvent -FilterHashtable @{LogName='System'; Level=2} -MaxEvents 10          # erreurs uniquement
Get-WinEvent -FilterHashtable @{LogName='System'; ProviderName='Service Control Manager'} -MaxEvents 15 |
    Format-Table TimeCreated, Id, Message -Wrap

6. Réseau et pare-feu

Commandes de diagnostic

Besoin Commande Windows Équivalent Linux
configuration IP ipconfig /all, Get-NetIPConfiguration ip a, ip route
tester une machine ping, Test-Connection ping
tester un port Test-NetConnection 10.10.10.20 -Port 22 nc -zv 10.10.10.20 22
résoudre un nom Resolve-DnsName, nslookup dig, getent hosts
ports en écoute Get-NetTCPConnection -State Listen, netstat -ano ss -tlnp
vider le cache DNS Clear-DnsClientCache, ipconfig /flushdns (selon le système)

Le pare-feu Windows Defender

Il est actif par défaut et fonctionne avec trois profils, choisis selon le réseau détecté : Domaine (réseau de l’entreprise, reconnu grâce au contrôleur de domaine), Privé, Public (le plus restrictif). Chaque profil a ses règles.

  • Les règles entrantes filtrent ce qui arrive, les règles sortantes ce qui part (autorisé par défaut).
  • Une règle définit : programme ou port, protocole, portée (adresses distantes autorisées), profils, action (autoriser ou bloquer).
  • Une règle de blocage l’emporte sur une règle d’autorisation.
  • De nombreuses règles prédéfinies existent, désactivées tant que le rôle correspondant n’est pas installé.
  • Par défaut, Windows ne répond pas au ping : il faut autoriser l’ICMP entrant.
Machine : SRV-WIN-01 (PowerShell administrateur)
Get-NetFirewallProfile | Select-Object Name, Enabled, DefaultInboundAction
Get-NetFirewallRule -Enabled True -Direction Inbound | Select-Object DisplayName, Action, Profile
New-NetFirewallRule -DisplayName "Lab - Ping entrant" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow
Get-NetFirewallRule -DisplayName "Lab - Ping entrant" | Get-NetFirewallAddressFilter   # portée

7. Le stockage

  • Un disque neuf doit être mis en ligne, initialisé avec un style de partition (GPT, moderne, ou MBR, ancien, limité à 2 To), puis partitionné et formaté.
  • Systèmes de fichiers : NTFS (standard, gère les permissions, les quotas, le chiffrement), ReFS (résilient, pour les gros volumes de données et la virtualisation), FAT32 et exFAT (supports amovibles, sans permissions).
  • On sépare le système (C:) des données (E:, F:…) : une restauration ou une réinstallation du système ne touche pas les données, et un volume de données plein n’empêche pas Windows de fonctionner.
  • La redondance se fait avec du RAID matériel ou les Espaces de stockage de Windows : RAID 1 (miroir, 2 disques), RAID 5 (parité, 3 disques minimum), RAID 10 (miroir + agrégat). Le RAID protège d’une panne de disque, pas d’une suppression ou d’un rançongiciel : il ne remplace pas une sauvegarde.
Machine : SRV-WIN-01 (PowerShell administrateur)
Get-Disk                                   # le nouveau disque apparaît en RAW, hors ligne ou non initialisé
Get-Disk | Where-Object PartitionStyle -eq 'RAW' |
    Initialize-Disk -PartitionStyle GPT -PassThru |
    New-Partition -DriveLetter E -UseMaximumSize |
    Format-Volume -FileSystem NTFS -NewFileSystemLabel "DATA" -Confirm:$false
Get-Volume

8. Les mises à jour

  • Microsoft publie ses correctifs de sécurité le deuxième mardi de chaque mois (Patch Tuesday), sous forme de mises à jour cumulatives : la dernière contient toutes les précédentes.
  • En entreprise, on ne met pas à jour tous les serveurs en même temps : on teste sur un groupe pilote, puis on déploie par vagues pendant une fenêtre de maintenance convenue, car la plupart des mises à jour demandent un redémarrage.
  • Outils : Windows Update, WSUS (serveur de mises à jour interne), Azure Update Manager, outils tiers.
  • Vérifier : Get-HotFix ou l’historique de Windows Update ; option 6 de sconfig.

9. Méthode de dépannage

Toujours : lire les journaux avant de modifier, ne changer qu’une chose à la fois, vérifier après chaque correction, noter ce qui a été fait.

10. À retenir

Points clés

  • Standard ou Datacenter selon les droits de virtualisation ; Server Core réduit la surface d’attaque.
  • Configuration initiale : nom, IP fixe, DNS, heure, mises à jour, accès distant, pare-feu.
  • Rôle = fonction rendue ; fonctionnalité = composant d’appoint ; service = programme en arrière-plan.
  • Un service a un état, un type de démarrage, un compte et des dépendances.
  • Journaux Système, Application, Sécurité ; ID 7000/7001 = service qui ne démarre pas.
  • Pare-feu : trois profils, le blocage l’emporte, le ping est refusé par défaut.
  • Disque neuf : en ligne, initialiser (GPT), partitionner, formater (NTFS). RAID ≠ sauvegarde.

Quiz

  1. Quelle édition choisir pour un hôte Hyper-V qui fera tourner 12 VM Windows Server ?
  2. Citez deux avantages de Server Core.
  3. IIS est-il un rôle, une fonctionnalité ou un service ? Et W3SVC ?
  4. Un service est en type de démarrage Désactivé. Que se passe-t-il si on clique sur Démarrer ?
  5. Quel journal consulter en premier quand un service refuse de démarrer ? Quel ID chercher ?
  6. Le serveur ne répond pas au ping mais le partage de fichiers fonctionne. Est-ce normal ?
  7. Une règle autorise le port 80, une autre le bloque. Qui gagne ?
  8. Quelles sont les quatre étapes pour rendre utilisable un disque neuf ?
  9. Pourquoi séparer le disque système et le disque de données ?
  10. Le RAID 1 protège-t-il contre la suppression accidentelle d’un fichier ?
Voir la correction
  1. Datacenter : VM Windows Server illimitées sur l’hôte.
  2. Surface d’attaque réduite, moins de mises à jour et de redémarrages, moins de ressources consommées.
  3. IIS est un rôle ; W3SVC est le service principal installé par ce rôle.
  4. Il refuse de démarrer : il faut d’abord changer le type de démarrage.
  5. Le journal Système, source Service Control Manager, ID 7000 ou 7001 (dépendance).
  6. Oui : Windows bloque le ping entrant par défaut, il faut une règle ICMP.
  7. La règle de blocage.
  8. Mettre en ligne, initialiser (GPT), créer une partition, formater.
  9. Pour pouvoir restaurer ou réinstaller le système sans toucher aux données, et pour qu’un volume de données plein ne bloque pas Windows.
  10. Non : le miroir réplique aussi la suppression. Seule une sauvegarde protège.
