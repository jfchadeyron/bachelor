TP 1 : Installer VirtualBox et une première VM Debian

Vous préparez votre poste d'administrateur : installation de VirtualBox, création d'une machine virtuelle et installation d'un serveur Debian 13 minimal qui servira de modèle à tous les serveurs Linux du lab.

Contexte

Votre responsable chez Hexalog vous demande de préparer un environnement de test sur votre poste avant de toucher aux serveurs de l’entreprise. Première étape : un hyperviseur et un serveur Linux « propre », à jour, qui servira de modèle (on dit aussi template) pour créer rapidement d’autres serveurs.

Objectifs

  • Vérifier que le PC hôte supporte la virtualisation.
  • Installer et configurer VirtualBox.
  • Créer une VM en choisissant ses ressources en connaissance de cause.
  • Installer Debian 13 en mode serveur, sans interface graphique.
  • Réaliser les premières commandes d’administration et un snapshot.

Prérequis

  • Un PC avec processeur 64 bits, 8 Go de RAM minimum (16 Go conseillés) et 80 Go d’espace libre.
  • Des droits administrateur sur le PC (pour installer VirtualBox).
  • L’image ISO Debian 13 netinst amd64 (fournie en séance ou téléchargée sur debian.org).

Architecture visée

Étape 1. Vérifier la virtualisation matérielle

Sur un hôte Windows : ouvrez le Gestionnaire des tâches, onglet Performances, puis Processeur. La ligne Virtualisation doit indiquer Activé.

Vérifiez aussi qu’Hyper-V n’est pas actif (sinon VirtualBox sera lent) :

Machine : PC hôte Windows (PowerShell)
# "Un hyperviseur a été détecté" en bas de la liste = Hyper-V ou VBS est actif
systeminfo | Select-String "Hyper-V"

Sur un hôte Linux :

Machine : PC hôte Linux
# un nombre supérieur à 0 = virtualisation disponible (vmx pour Intel, svm pour AMD)
grep -Ec '(vmx|svm)' /proc/cpuinfo
lscpu | grep -i virtuali

Si la virtualisation est désactivée, il faut l’activer dans le BIOS/UEFI (menu souvent nommé Intel Virtualization Technology, VT-x ou SVM Mode). Sur un PC du lycée, signalez-le à M. CHADEYRON : l’accès au BIOS peut être protégé par un mot de passe.

Étape 2. Installer VirtualBox

  1. Téléchargez la dernière version 7.x de VirtualBox pour votre système depuis virtualbox.org (ou utilisez l’installeur fourni).
  2. Windows : lancez l’installeur, acceptez les options par défaut. L’installation coupe brièvement le réseau (création d’une carte réseau virtuelle) et peut demander d’installer le Microsoft Visual C++ Redistributable.
  3. Linux (Debian, Ubuntu, Mint) : installez le paquet .deb fourni par Oracle, puis ajoutez votre utilisateur au groupe vboxusers et reconnectez-vous.
Machine : PC hôte Linux
sudo apt install ./virtualbox-7.*.deb
sudo usermod -aG vboxusers $USER

L’Extension Pack n’est pas nécessaire pour ce bloc.

  1. Ouvrez VirtualBox, menu Fichier → Paramètres (ou Préférences) :
    • Général → Dossier par défaut des machines : vérifiez qu’il est sur un disque avec assez d’espace ;
    • Entrée → Machine virtuelle → Touche hôte : notez-la (par défaut Ctrl droit). Elle sert à libérer la souris et le clavier capturés par une VM.

Avant de démarrer, ouvrez Configuration et vérifiez :

  • Réseau → Adaptateur 1 : activé, mode d’accès NAT (par défaut) ;
  • Système → Carte mère : ordre d’amorçage avec le disque optique avant le disque dur ;
  • Stockage : l’ISO est bien insérée dans le lecteur optique.

Pourquoi le NAT ?

En mode NAT, la VM sort sur Internet en utilisant la connexion de votre PC, comme un appareil derrière une box. Elle peut télécharger ses paquets, mais personne ne peut la joindre depuis l’extérieur. Au lycée, elle profite aussi de l’identification de votre PC sur le portail du pare-feu (page web avec identifiant et mot de passe). Les autres modes réseau sont étudiés à la séance 2.

Étape 4. Installer Debian 13

Avant de démarrer la VM, vérifiez que votre PC est identifié sur le portail du lycée : ouvrez un site dans le navigateur et, si la page d’authentification s’affiche, saisissez vos identifiants. Sans cela, l’installeur ne pourra pas joindre le miroir Debian.

Démarrez la VM. Dans le menu d’installation, choisissez Install (mode texte) ou Graphical install. Déplacez-vous avec les flèches et Tab, validez avec Entrée, cochez avec Espace.

Pourquoi laisser le mot de passe root vide ?

Dans ce cas, Debian verrouille le compte root, installe sudo et donne les droits d’administration au premier utilisateur (sysadmin) via le groupe sudo. On administre alors avec son propre compte et sudo, ce qui laisse une trace de qui a fait quoi. C’est la bonne pratique.

À la fin, l’installeur demande de retirer le support : VirtualBox éjecte normalement l’ISO tout seul. Validez, la VM redémarre sur le disque.

Étape 5. Premières commandes

Connectez-vous avec sysadmin sur la console de la VM. Tapez chaque commande, lisez le résultat et notez l’essentiel dans votre journal.

Machine : TPL-DEB13 (sysadmin)
cat /etc/os-release        # quelle distribution et quelle version ?
hostnamectl                # nom de la machine, noyau, virtualisation détectée
whoami                     # sous quel compte suis-je ?
id                         # mon UID, mes groupes (repérez le groupe sudo)
ip -br a                   # interfaces réseau et adresses IP (format court)
ip route                   # table de routage : repérez la passerelle par défaut
cat /etc/resolv.conf       # serveur DNS utilisé
ping -c 3 deb.debian.org   # la VM sort-elle sur Internet ?
free -h                    # mémoire
df -h                      # espace disque par système de fichiers
lsblk                      # disques et partitions

Mettez le système à jour et installez quelques outils utiles pour la suite :

Machine : TPL-DEB13 (sysadmin)
sudo apt update                 # rafraîchit la liste des paquets disponibles
sudo apt full-upgrade -y        # installe les mises à jour
sudo apt install -y curl bind9-dnsutils traceroute tcpdump

Le premier sudo demande votre mot de passe (celui de sysadmin), pas celui de root.

Étape 6. Arrêter proprement et prendre un snapshot

Machine : TPL-DEB13 (sysadmin)
sudo poweroff

Dans VirtualBox, sélectionnez la VM, ouvrez l’outil Instantanés (icône en forme de liste à côté du nom de la VM), puis Prendre :

  • nom : 01-installation-propre ;
  • description : « Debian 13 installé, à jour, outils réseau, utilisateur sysadmin ».

Un snapshot mémorise l’état exact de la VM à un instant. Si vous cassez quelque chose plus tard, vous pouvez revenir à cet état en quelques secondes.

Étape 7. Regarder la VM de l’extérieur

Ouvrez le dossier des machines virtuelles sur votre PC (par défaut VirtualBox VMs/TPL-DEB13) et observez :

  • le fichier TPL-DEB13.vbox : ouvrez-le avec un éditeur de texte, retrouvez la quantité de RAM et le type de carte réseau ;
  • le fichier .vdi : quelle est sa taille réelle sur le disque comparée aux 20 Go annoncés ?
  • les dossiers Logs et Snapshots.

Pour aller plus loin

VirtualBox se pilote aussi en ligne de commande avec VBoxManage, ce qui permet d’automatiser :

Machine : PC hôte (terminal ou PowerShell)
VBoxManage list vms                       # toutes les VM
VBoxManage list runningvms                # VM démarrées
VBoxManage showvminfo TPL-DEB13           # configuration détaillée
VBoxManage snapshot TPL-DEB13 list        # snapshots

Sous Windows, si la commande n’est pas trouvée, lancez-la depuis C:\Program Files\Oracle\VirtualBox\.
