TP 5 : Installer SRV-WIN-01 et créer le domaine

Vous installez Windows Server 2025 dans le lab, vous lui donnez son nom et son adresse fixe, puis vous en faites le contrôleur du domaine hexalog.local. C'est la base de toute la partie Windows : le poste de travail et les comptes du TP 6, les dossiers partagés du TP 7.

Contexte

Hexalog a besoin d’un serveur Windows qui gérera les comptes des salariés et les dossiers partagés. Ce serveur, SRV-WIN-01, sera le contrôleur du domaine hexalog.local.

Où en êtes-vous ?

Si votre SRV-WIN-01 a l’adresse 10.10.10.10 et que le domaine hexalog.local existe (vous ouvrez la session HEXALOG\Administrateur), passez directement au TP 6 : Un poste Windows 11 dans le domaine. Sinon, reprenez à l’étape qui manque : l’étape 6 permet de vérifier où vous en êtes.

Objectifs

  • Installer Windows Server en mode Expérience de bureau dans VirtualBox.
  • Donner au serveur son nom et une adresse IP fixe.
  • Installer le rôle Services AD DS et créer le domaine hexalog.local.
  • Vérifier que le domaine et son DNS fonctionnent.

Prérequis

  • L’ISO Windows Server 2025 Evaluation en français (fournie en séance).
  • 4 Go de mémoire pour la VM, 2 Go si votre PC n’a que 8 Go (éteignez alors les VM Linux).

Architecture en fin de TP

Étape 1. Créer la VM

Nouvelle machine virtuelle :

Champ Valeur
Nom SRV-WIN-01
Image ISO Windows Server 2025 Evaluation
Type / version Microsoft Windows / Windows 2025 (64 bits) ou la plus récente proposée
Ignorer l’installation automatique (Skip Unattended Installation) coché
Mémoire / processeurs 4096 Mo (2048 Mo sur un PC de 8 Go) / 2
Disque VDI dynamique de 50 Go

Puis Configuration → Réseau → Adaptateur 1 : Réseau NAT → LAB-HEXALOG.

Étape 2. Installer Windows Server

  1. Démarrez la VM. Si le message Press any key to boot from CD or DVD apparaît, appuyez tout de suite sur une touche dans la fenêtre de la VM.
  2. Langue, format horaire, clavier : Français. Choisissez Installer Windows Server.
  3. Édition : Windows Server 2025 Standard Evaluation (Expérience de bureau).
  4. Type d’installation : Personnalisée, sur le disque de 50 Go (non alloué).
  5. Mot de passe du compte Administrateur : le mot de passe de lab (Windows exige 8 caractères minimum avec majuscules, minuscules, chiffres ou symboles).
  6. Pour ouvrir la session : menu Entrée → Clavier → Insérer Ctrl-Alt-Suppr (ou touche hôte + Suppr).

L’installation dure 20 à 30 minutes. N’appuyez sur aucune touche aux redémarrages, sinon elle recommence.

Installez ensuite les Additions invité (meilleur affichage, souris fluide, presse-papiers) : menu Périphériques → Insérer l’image CD des Additions invité, ouvrez le lecteur CD dans l’Explorateur, lancez VBoxWindowsAdditions.exe, acceptez, redémarrez. Réglez Périphériques → Presse-papiers partagé → Bidirectionnel.

Faites un snapshot 05-installation-propre.

Étape 3. Le nom et l’adresse fixe

3.1, Relever la configuration reçue

Le serveur a reçu une adresse automatiquement (DHCP de VirtualBox). Ouvrez un terminal (clic droit sur le menu Démarrer → Terminal) :

Machine : SRV-WIN-01 (Terminal)
hostname          # un nom aléatoire, WIN-…
ipconfig /all     # repérez l'adresse IPv4, la passerelle et la ligne « Serveurs DNS »

Notez dans votre journal l’adresse de la ligne Serveurs DNS : vous allez la réutiliser.

3.2, Adresse fixe

Un serveur doit toujours être à la même adresse : les autres machines doivent le retrouver.

  1. Touches Windows + R, tapez ncpa.cpl, Entrée.
  2. Clic droit sur Ethernet → Propriétés → double-clic sur Protocole Internet version 4 (TCP/IPv4).
  3. Utiliser l’adresse IP suivante : adresse 10.10.10.10, masque 255.255.255.0, passerelle 10.10.10.1.
  4. Serveur DNS préféré : l’adresse notée au 3.1. OK, OK.

3.3, Le nom

Gestionnaire de serveur → Serveur local → cliquez sur le nom à côté de Nom de l’ordinateur → Modifier… → SRV-WIN-01 → OK → redémarrez.

3.4, Vérifier

Machine : SRV-WIN-01 (Terminal)
hostname                      # SRV-WIN-01
ipconfig /all                 # 10.10.10.10, passerelle 10.10.10.1
nslookup www.microsoft.com    # le serveur trouve les noms d'Internet

Faites un snapshot 05-config-initiale.

Étape 4. Installer le rôle Services AD DS

  1. Gestionnaire de serveur → Gérer → Ajouter des rôles et des fonctionnalités.
  2. Suivant, Installation basée sur un rôle ou une fonctionnalité, serveur SRV-WIN-01.
  3. Cochez Services AD DS, acceptez Ajouter des fonctionnalités (les outils d’administration).
  4. Suivant jusqu’au bout, puis Installer. Attendez la fin, puis Fermer.

Le rôle est installé, mais le serveur n’est pas encore contrôleur de domaine : un drapeau jaune apparaît en haut du Gestionnaire de serveur.

Étape 5. Créer le domaine hexalog.local

Cliquez sur le drapeau jaune → Promouvoir ce serveur en contrôleur de domaine :

  1. Ajouter une nouvelle forêt ; nom de domaine racine : hexalog.local.
  2. Options : laissez les choix par défaut (Serveur DNS et Catalogue global cochés). Mot de passe DSRM : le mot de passe de lab.
  3. Options DNS : l’avertissement sur la délégation est normal dans un lab. Suivant.
  4. Nom NetBIOS : HEXALOG (proposé automatiquement).
  5. Chemins : laissez les valeurs par défaut.
  6. Examen des options : cliquez sur Afficher le script pour voir la commande PowerShell équivalente, puis fermez.
  7. Vérification de la configuration requise : des avertissements jaunes sont normaux. Installer.

Le serveur redémarre tout seul. Le premier démarrage d’un contrôleur de domaine est long (« Application des paramètres… ») : plusieurs minutes, c’est normal.

Ce que la promotion a fait

Elle a créé l’annuaire du domaine, installé le serveur DNS avec la zone hexalog.local, réglé le serveur pour qu’il s’interroge lui-même comme DNS (127.0.0.1) et gardé l’ancien DNS comme redirecteur pour les noms d’Internet. Le mot de passe DSRM sert à réparer l’annuaire en cas de problème grave : notez-le dans votre journal.

Étape 6. Vérifier le domaine

Ouvrez la session : l’écran indique maintenant HEXALOG\Administrateur (même mot de passe qu’avant).

Machine : SRV-WIN-01 (Terminal)
ipconfig /all                 # serveur DNS : 127.0.0.1 (ou ::1), le serveur lui-même
nslookup hexalog.local        # répond 10.10.10.10
nslookup www.microsoft.com    # toujours possible, grâce au redirecteur
Get-ADDomain | Select-Object DNSRoot, NetBIOSName      # hexalog.local, HEXALOG

Puis ouvrez deux consoles depuis le menu Outils du Gestionnaire de serveur :

  • Utilisateurs et ordinateurs Active Directory : dépliez hexalog.local ; le serveur est dans Domain Controllers, le compte Administrateur dans Users ;
  • DNS : dépliez SRV-WIN-01 → Zones de recherche directe → hexalog.local ; repérez l’enregistrement de srv-win-01.

Faites un snapshot 05-domaine et complétez votre inventaire (système, adresse, rôles AD DS et DNS, domaine).

Vérifications

  • hostname renvoie SRV-WIN-01 ; adresse 10.10.10.10/24, passerelle 10.10.10.1.
  • La session HEXALOG\Administrateur s’ouvre.
  • nslookup hexalog.local répond 10.10.10.10 ; nslookup www.microsoft.com répond aussi.
  • Snapshot 05-domaine pris.

Questions

  1. Quelle adresse le serveur avait-il juste après l’installation ? D’où venait-elle ?
  2. Pourquoi faut-il une adresse fixe avant de créer le domaine ?
  3. Quelle est la différence entre installer le rôle AD DS et promouvoir le serveur ?
  4. Quel DNS le serveur utilise-t-il après la promotion ? Comment trouve-t-il encore les noms d’Internet ?
  5. Que contient la zone DNS hexalog.local juste après la promotion ?

L’installation recommence au redémarrage une touche a été pressée au message Press any key : laissez démarrer sans toucher le clavier, ou retirez l’ISO (Configuration → Stockage)

Pour aller plus loin

La promotion en PowerShell

Les étapes 4 et 5 tiennent en deux commandes (c’est le script affiché par Afficher le script) :

Machine : SRV-WIN-01 (PowerShell administrateur)
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "hexalog.local" -DomainNetbiosName "HEXALOG" -InstallDns `
    -SafeModeAdministratorPassword (Read-Host -AsSecureString "Mot de passe DSRM") -Force

Le bureau à distance depuis votre PC

  1. Sur SRV-WIN-01 : Gestionnaire de serveur → Serveur local → Bureau à distance → Autoriser les connexions à distance.
  2. Dans VirtualBox : Fichier → Outils → Gestionnaire de réseau → Réseaux NAT → LAB-HEXALOG → Redirection de ports, ajoutez la règle rdp-dc : TCP, IP hôte 127.0.0.1, port hôte 33890, IP invité 10.10.10.10, port invité 3389.
  3. Sur votre PC Windows : mstsc, ordinateur 127.0.0.1:33890, utilisateur HEXALOG\Administrateur. Acceptez l’avertissement de certificat.

Explorer le serveur

Machine : SRV-WIN-01 (PowerShell)
Get-ComputerInfo | Select-Object WindowsProductName, OsVersion, CsName, CsDomain
(Get-Service | Where-Object Status -eq 'Running').Count      # nombre de services démarrés
Get-WindowsFeature | Where-Object Installed | Select-Object Name, DisplayName
Get-Service NTDS, DNS                                        # les services de l'annuaire et du DNS

Les notions correspondantes (services, journaux, pare-feu) sont dans les compléments du Séance 5 : Windows Server : les fondamentaux.
