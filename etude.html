// Étape 1 — OVH Cloud
1
OVH Aller sur la page VPS

Rendez-vous sur la page officielle OVH VPS. Repérez l'offre VPS Comfort (4 vCore, 8 Go RAM, 160 Go NVMe). C'est l'offre la plus proche de notre scénario.

→ ovhcloud.com/fr/vps/
📸 Capture d'écran de la page tarifaire OVH avec le prix visible
2
OVH Relever les coûts OVH

Notez dans votre tableau les postes suivants chez OVH :

Instance VPS Comfort → prix affiché /mois  |  Stockage → inclus dans l'offre  |  Trafic 1 To → illimité inclus  |  IPv4 → incluse  |  Backup / Snapshot → option payante, noter le prix

⚠️ Vérifiez si le trafic est bien illimité en Europe (petites lignes en bas de page)
// Étape 2 — Amazon AWS
3
AWS Ouvrir le calculateur AWS

AWS ne publie pas de tarif "tout-en-un". Il faut utiliser le calculateur officiel et ajouter chaque poste manuellement.

→ calculator.aws
📸 Capture d'écran de votre estimation finale dans le calculateur AWS
4
AWS Ajouter l'instance EC2

Dans le calculateur, cliquez sur « Ajouter un service » → cherchez EC2. Sélectionnez :

Région : Europe (Paris) — eu-west-3  |  OS : Linux  |  Instance : m6i.large (2 vCPU, 8 Go)  |  Utilisation : 100 % / mois (On-Demand)

💡 Pas d'instance 4 vCPU / 8 Go chez AWS → m6i.large est le plus proche en RAM. Notez cet écart dans votre rapport.
5
AWS Ajouter le stockage EBS

Dans le même calculateur, ajoutez le service EBS (Elastic Block Store). Choisissez :

Type : gp3 (SSD généraliste)  |  Taille : 80 Go  |  Région : Europe (Paris)

⚠️ Sur AWS, le stockage n'est PAS inclus dans l'instance — c'est un service séparé facturé à la Go
6
AWS Calculer le trafic réseau sortant

AWS facture le trafic sortant vers Internet. Appliquez la règle suivante :

Tarif : 100 Go gratuits/mois, puis 0,09 $/Go (premiers 10 To) en région Paris.
Calcul : 1 000 Go − 100 Go gratuits = 900 Go facturés × 0,09 $

📌 Le trafic entrant (upload vers votre serveur) est gratuit chez AWS
7
AWS Ajouter l'adresse IPv4 publique

Depuis février 2024, AWS facture toute adresse IPv4 publique, même attachée à une instance active.

Tarif : 0,005 $/heure × 730 h = ~3,65 $/mois

💡 Ce coût est souvent oublié — il est pourtant obligatoire pour exposer un serveur web
8
AWS Ajouter les snapshots EBS (backup)

Un snapshot EBS est une photo instantanée de votre volume à un instant T, stockée dans S3. C'est le mécanisme de backup natif d'AWS. Contrairement à OVH où le snapshot est une option forfaitaire, AWS facture au Go réellement stocké dans le snapshot.

Comment ça marche : le 1er snapshot = copie complète du volume (80 Go). Les suivants sont incrémentaux (seules les données modifiées sont facturées).

Tarif : 0,05 $/Go/mois sur la capacité occupée par le snapshot.
Calcul pour 1 snapshot complet de 80 Go : 80 × 0,05 $ = 4 $/mois ≈ 3,68 €/mois

⚠️ Si vous conservez plusieurs snapshots (ex. 1/semaine = ~4/mois), le coût se multiplie. Avec 4 snapshots : ~16 $ ≈ 14,70 €/mois — à comparer avec l'option snapshot OVH à prix fixe.
📌 Différence clé OVH vs AWS : chez OVH, le snapshot est une option à prix fixe mensuel. Chez AWS, le coût varie selon la taille du volume et le nombre de snapshots conservés.
